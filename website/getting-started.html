Start with the Mac app and a supported API key. OpenRouter is the first connection to try; direct provider keys are alternatives. You can run a project with one provider, or choose different providers for the author and reviewer.

  1. 01

    Get the Mac beta.

    Download the disk image, open it, and drag Sprout Crew into Applications. Launch it from Applications. It runs on Macs with Apple Silicon (M1 or newer).

    Download & installation details ↗
  2. 02

    Create your own API key.

    We recommend OpenRouter. Create an account there and make an API key. Treat it like a password. Check OpenRouter’s current free-model availability and limits before choosing a model. A multi-step project can use several requests.

    Alternatively, make a key at Anthropic or OpenAI. Direct API usage has its own billing. A subscription login alone does not connect API access. Provider API credits, when offered, have separate eligibility and expiry conditions. Claude subscriptions do not cover Anthropic API use.

  3. 03

    Connect it in Settings.

    Open Settings → AI connections, paste the key into its provider card, and choose Check and save. Sprout Crew validates it with a read-only account or models request before saving it to this Mac’s Keychain. That check is not a model generation request.

    Paid OpenRouter models stop at $5 for each project, and you can raise that limit for a project in Usage & limits. There is also a token limit shared by all projects. Set spending controls with your provider too. OpenAI project budgets may alert you without blocking further charges.

  4. 04

    Give your crew a small first job.

    Choose New project. Pick Writing & editing under It should make, and describe the audience, purpose, length and voice in the brief. Add a source or two with Files, then choose Create project. The plan shows what will run, who writes and who checks, what it may do, the most it can cost and the version you are approving. It also waits on the Board, the first screen. Choose Approve and start. Nothing runs before you approve.

    New projects write with Claude Haiku 5.5 and check with Mistral Small, both paid models through OpenRouter, so a first project needs a little credit on your OpenRouter account. The plan shows the estimate before you approve. Unfinished setup is not saved; created projects are saved on this Mac and reopen with the app.

    Try: “Write a 500-word newsletter for product managers using these customer interview notes. Be direct, cite the notes, and separate evidence from assumptions.”

What to know about this beta

  • Research uses your sources, and the web only if you turn it on. Add files, folders and public URLs. Web research is a choice when you create a project: it needs a paid model, OpenRouter charges a small fee for each search, and the research step sees only your brief, never your files.
  • Free models are available, with limits. The model picker lists every OpenRouter model with its price and marks the free ones. Free models allow few requests a minute and a day, and can stop a multi-step project or return an empty answer. Sprout Crew never moves a step to a paid model unless you choose it and approve the plan. OpenRouter’s Logs → Upstream Requests can show a rejected attempt even when its Generations view is empty. A failed request may have consumed allowance; inspect the status before retrying.
  • Privacy filters may reduce availability. OpenRouter requests exclude providers that may collect data. If no eligible endpoint is available, the request fails; the app keeps this restriction.
  • Models can make mistakes. A second pass on one provider is not independent verification. Check sources, facts, quotations, and final wording yourself.
  • Stop prevents further work. An API request already sent may finish or be billed before its connection returns. The app records usage when available.
  • Memory is what you see on the Memory screen. Notes for one project, and notes for every project, persist across restarts and are sent with later requests. You can edit or delete any of them. There is no cloud sync. Removing a note does not erase past results or request records.
  • Projects that write code are off until you turn them on. With Allow projects that write running code on in Settings, App development and clickable prototypes are offered. Code is shown for review, a prototype opens only in the app’s own preview, and the crew never runs commands on your Mac.
  • The crew does not operate your Mac. It does not capture your screen, click, type into other apps, or operate your browser. The one exception is Build the deck in Keynote, which you choose for a plan and which makes a new deck without touching your other files.
  • Run reports keep the context. Results & sharing exports the approved scope, guardrails and review history as Markdown and PDF, and the finished work as Word, PowerPoint, PDF and an Excel sheet of its tables. The Board lists every decision waiting across your projects, and you decide most of them there.
  • Updates are manual in this build. Download a later version from this website when available.

If something goes wrong

Key refused: copy the complete API key from the correct provider, and check it has not expired or been revoked. Do not paste a ChatGPT or Claude login token.

Rate limit: wait for your provider’s allowance to reset, or choose another model. A larger Sprout Crew limit cannot raise your provider’s limit.

Out of credit, or a key at its spending limit: add credit or raise the key’s limit with your provider, then choose Try again. More answers are on the help page.

No output: inspect the step’s error, reduce your source size or choose an available model, then rerun the step. A changed plan needs a new approval.

Export missing: finish the writing steps first. Save Markdown if a formatted export cannot be created.

Need help? hello@sproutcrew.app. Do not send API keys or confidential project files.
