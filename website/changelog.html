2.1.0 Current download

November 17, 2026

The first release shaped by a hands-on review of 2.0.5. Setup is shorter, the guardrails are on one screen, and the app does more with your own files and tools. Download 2.1.0.

Added

  • The review board. The plan, the guardrails and the cost are on one screen, with one button to approve and start.
  • Model picker. Every OpenRouter model, searchable, with its price and a label on the free ones. Each step can have its own model.
  • A dollar limit for each project. Paid OpenRouter models stop at $5 a project unless you raise it. The estimate and the most a run could cost are shown before you approve.
  • Web research. An optional first step that searches the web from your brief alone, never your files, and lists every page it used. A page becomes a source only when you add it.
  • Memory you can see. Notes for one project and notes for every project, on a Memory screen where each can be edited or deleted.
  • Your own templates. Import a Word, PowerPoint or PDF file and choose what to keep: the look, the sections, the writing style.
  • Excel output. The tables in a finished document as a spreadsheet of values.
  • Usage and cost view. Cost and tokens by day, month, role and model, a spreadsheet export, and a menu-bar item with today's totals.
  • More connections. A Google Gemini key, and your own AI service at any https address or an app running on this Mac.
  • Providers keep nothing. A plan choice that sends requests only to endpoints that state they store nothing, and refuses the rest.
  • Notion, folders and Google Docs. Read a Notion page as text, add a result to the end of a page you choose, read a folder with its subfolders, save a result into a folder, and read a Google Doc with a view-only sign-in.
  • Build the deck in Keynote. A choice on the review board for plans that make slides. Keynote builds a new deck, which is then read back and compared with the slides.
  • Pictures as sources for models that can read images.
  • Quick brainstorm in four steps, an optional polish step for finished text, and a step that challenges an app specification before any code is written.
  • Alerts for a run that finished, stopped or is waiting on a limit, with no project text in them.
  • How your crews have done. A summary on Home, worked out on your Mac from your own projects.
  • A log for bug reports. A small local file you can export and send. It never holds your text, file names or keys.
  • Projects that write code, behind a switch in Settings that is off until you turn it on, with clickable prototypes in the app's own preview.
  • A help page that is updated in the same change as each feature.

Changed

  • Starting a project takes four actions: pick an outcome, write the brief, create, approve. The brief is the only thing you must type.
  • New projects write with one paid model and check with a different maker's model, in place of the free router that often failed mid-run.
  • Every screen says less. Repeated and internal wording is gone, and nothing that protects you is hidden behind a disclosure.
  • Rate limits and empty accounts are explained in one sentence, with a sensible retry for the kinds a short wait can clear.
  • The download is for Apple Silicon and is half the size: 31.8 MB, down from 64.8 MB.

Fixed

  • Sending a result to Notion or GitHub could skip the check for sending outside this Mac. It now always runs.
  • The Share tab said nothing leaves the Mac. It now says what is true: results leave only after you approve, and your brief and sources go to the AI service you chose.
  • The coordinator could propose a model on a service this Mac is not connected to.
  • A key that reached its own spending limit was reported as a refused key.

Security

  • A reviewer with no network access and no credentials read every change since 2.0.5. No high-severity issue was found. One medium and six low findings were fixed before release, including a way for the coordinator to add a code-writing step while that switch was off.
  • The program for operating other apps is not in this build, because no step can use it yet.

Removed

  • Support for Intel Macs. The app now contains no Intel code.

2.0.5 First public beta

November 9, 2026

The first build offered to the public, free, with your own API keys.

Changed

  • Word files are written by code inside the app, PowerPoint files by an embedded script engine with no access to your files or the network, and PDFs by Typst. The bundled converter used before is gone.
  • The download fell from 131 MB to 64.8 MB.

Added

  • A software notices page with the exact source of the open-source parts that require it.
  • Word and PowerPoint files that open without repair prompts, with real tables and presenter notes.

Known at release

  • Setup that is not finished is not saved. Only Create project saves the project.
  • Updates are manual.

2.0.1 to 2.0.4 Release candidates

Through November 8, 2026

Four signed candidates that were reviewed and not offered publicly. Each closed something the review before it found.

Changed and fixed

  • 2.0.4. A cost reported by the provider is kept even when a connection is limited by tokens, and never shown as zero when it is unknown.
  • 2.0.3. The first paid end-to-end run exposed export and prompt problems on API connections, which were fixed with tests.
  • 2.0.2. Optional Mac alerts that lead back to the Decision inbox. An approval now covers the guardrails and the sources as well as the plan, so changing any of them needs a new approval.
  • Subscription sign-ins were switched off. The app connects through API keys only.

2.0.0 Private beta

November 2, 2026

The first signed and notarized Mac app, shared with a few people.

Added

  • Two-provider crews: one writes, the other checks.
  • Ready-made outcomes for a case study, a proposal, a research brief, social posts and a brainstorm.
  • Sources from Word, Excel, PowerPoint, PDF, scans and web pages.
  • Spending and token limits, a decision log, and export to Word, PDF and slides.
  • Keys kept in the macOS Keychain.

V1 Prototype

October 31 to November 1, 2026

A working prototype built for one person's own case-study practice. It proved the idea that a second model should check the first, and that a person should approve the plan before anything runs.
