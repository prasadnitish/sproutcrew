Privacy

Last updated November 16, 2026 · Applies to the website and Mac beta.

Your project stays local; AI requests leave your Mac

SproutCrew stores projects, sources, results, conversations, project memory, usage records, and decision logs in this Mac’s application data folder. There is no SproutCrew account, built-in cloud sync, or SproutCrew inference server. The app has no analytics and sends us nothing about how you use it.

When you start work or ask an AI question, the selected API service receives the brief and the context needed for that request. This may include source text, requirements, notes, previous results, and your question. OpenRouter receives requests and routes them to an inference provider. The service and provider’s own privacy and retention policies apply.

You choose the service: OpenRouter, Anthropic, OpenAI, Google Gemini, or an AI service at an address you type. An address you type receives the same brief, sources and results as any other service, so use one you trust. It must use https, except for an app running on this Mac. If you choose a model that reads images, up to four picture sources are sent with the request.

If you turn on web research for a project, the research step sends your brief, and never your files, to the AI service’s search tool, which sends search queries to its search provider. The step lists every page it used. A page is fetched and kept as a source only when you choose to add it.

On the review board you can choose that AI providers keep nothing. Requests then go only to OpenRouter endpoints that state they do not store prompts or answers, and steps that cannot meet this are refused. This relies on what those providers state; SproutCrew cannot verify it.

API keys

Keys you paste into AI connections are checked with the selected service and saved under the sproutcrew service in macOS Keychain. The app reads the key when sending an authenticated request and does not intentionally put it in project logs or exports. Removing a key in the app deletes its Keychain item; revoke it with the provider to cancel it there.

This beta does not connect ChatGPT or Claude subscriptions and does not ask for their cookies or login tokens.

Sources, memory, and exports

Adding a public URL fetches that page; its host sees the request. Files may be processed locally with the bundled document tools or macOS text recognition. Files and extracted text are stored as project snapshots. Memory notes are stored on this Mac and are sent with later AI requests: a project’s notes with that project’s requests, and notes you save for every project with every project’s requests. A template you import is read on this Mac for its fonts, colours, logo, headings and, if you ask for it, a short note on its writing style.

Removing a memory note stops future use of it. It does not remove earlier results, request traces, or the decision log. Archived projects remain on disk. Exported copies and backups are separate from app data. To remove local data entirely, remove the relevant project folder and any exports or backups you made.

Sharing is your choice

Optional Notion or GitHub connectors receive the data you explicitly read or approve for writing. Reading a Notion page sends that page’s address to Notion with your integration key. Writing makes a new page or adds to the end of a page you choose, after you approve the exact text. Review the exact content and destination before sending. SproutCrew does not make an API key private from the service that authenticates it.

If you connect Google Docs, Google’s sign-in page opens in your browser and you allow SproutCrew to view your documents. The sign-in is kept in macOS Keychain, the app only reads the documents you paste a link to, and Disconnect forgets the sign-in. Saving a result into a folder writes a new file there and never replaces one.

Other apps and macOS permissions

If you choose Build the deck in Keynote for a plan, macOS asks once whether SproutCrew may control Keynote. SproutCrew then makes a new deck in the project’s folder and reads it back to check it. It does not open or change your other files. You can withdraw the permission in System Settings, Privacy & Security, Automation. SproutCrew asks for a macOS permission only when you turn on the feature that needs it.

Logs and alerts

The app keeps a small log on this Mac with errors, failed steps by kind, connection checks and the app version. It does not record your briefs, results, file names or keys. Nothing is sent unless you choose Export a log for a bug report in Settings and send the file yourself. Mac alerts, if you turn them on, never include your text, and include the project name only if you allow it.

This website

The website sets no analytics or advertising cookies, has no sign-up form, and serves its fonts and media locally. It is hosted by Cloudflare, which may process IP addresses and standard request information to operate and protect its network. See Cloudflare’s privacy policy. Following an external link sends your browser to that service.

Support and changes

If you email support, we receive the details you choose to send. Do not include API keys or confidential source files. Contact hello@sproutcrew.app. We will update this notice as the beta changes.
